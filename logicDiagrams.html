01 / Switch it on

Small gates. Big decisions.

A Boolean value has just two possibilities: 1 = True and 0 = False. A logic gate takes input values and produces one output. Start by changing the inputs.

The highlighted row matches your switches. OR includes the case where both inputs are 1. NOT has only one input.

Try all three gates

Two keys to open a safe.

The safe opens only when key A and key B are turned. Which gate represents this?

Choose a gate, then try its switches.
How do I recognise the symbols?

AND: a flat left edge and rounded right edge.
OR: a curved left edge and pointed right edge.
NOT: a triangle with a small circle at its output. The circle means inversion (flip the value).

A gate diagram, a Boolean expression and a truth table can describe the same decision.

02 / Every possibility

One row. One combination.

A truth table lists every possible input combination exactly once. With n inputs there are 2ⁿ rows: 1 input → 2 rows; 2 → 4; 3 → 8.

Work down each column. Check as often as you like.
Show the worked table

For three inputs, A stays 0 for four rows, B changes every two rows and C changes every row. Another row order is fine if no combination is missed or repeated.

03 / Read a diagram

Follow the wires, one gate at a time.

Choose the inputs, predict the output, then reveal each gate. An intermediate output becomes the input to the next gate.

    A number on each wire shows its signal. A question mark means it has not been revealed yet; it is not an extra Boolean value.

    05 / From words to logic

    Turn a condition into a bit.

    A toy greenhouse controller opens a vent if it is too hot or too humid, but only during the day. Try values just below and exactly at the thresholds.

    A = temperature >= 40
B = humidity >= 75
C = night
if (A OR B) AND NOT C then
    print("Open vent")
else
    print("Keep vent closed")
endif

    Link to algorithms: the same Boolean expression can control a selection in pseudocode. This is a classroom model, not a real greenhouse control system.

    Predict before you change it

    It is 40°C, humidity is 74%, and it is night. What happens?

    Use the conditions, including the night input.

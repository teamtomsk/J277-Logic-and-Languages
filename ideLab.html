05 / IDE Lab
From source code to output.
The editor changes code. A translator processes source code so it can be executed. The run-time environment supports running the program.
Quick recap: compiler or interpreter?
A compiler translates a program before the resulting code is run. An interpreter translates and executes instructions as the program runs. These are the GCSE models; real implementations can combine techniques.
An IDE can bring these tools together. It is not itself a programming language. The CPU ultimately executes machine instructions.

06 / IDE Lab
Try it in your own IDE.
Use the Python IDE you normally use at school. The browser activities prepare you; this short task gives you practice with the real tools.
The score-counter challenge
  1. Open the file in your usual IDE. Run it. The target is 30, but the output is 10.
  2. Find syntax highlighting or line numbers. Explain how it helps you.
  3. Remove the closing bracket from print(score). Run and read the message. Put the bracket back.
  4. If your IDE has a debugger, set a breakpoint on score = 10. Step through and watch score. Ask your teacher where these controls are if needed.
  5. Change score = 10 to score = score + 10. Restart and run. Check that it prints 30.
If debugger controls are unavailable
Use the browser debugger in section 4 to practise pausing and stepping. Still complete editing, running and reading an error message in your real IDE. Ask your teacher for a demonstration of its debugging tools.

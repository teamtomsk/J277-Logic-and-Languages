    03 / Defensive design

    Right format. Right copy?

    Verification checks that data matches its source or a second entry. That is a different job from validation.

    Copy a booking code

    Original code: AB-123

    Use two capital letters, a hyphen and three digits. Enter the code twice, then compare the results.

    05 / Defensive design

    Put your logic to work.

    Use AND to accept values inside a range. Use OR to spot values outside it. Complete this short username check.

    Keep asking until the length is allowed

    A username must contain 5 to 10 characters. Spaces count as characters in this simple length-only example.

    username = input("Choose a username")
while length(username) < 5 [A] length(username) > 10
    username = input("Use 5 to 10 characters. Try again")
endwhile
print("Length accepted")
    Show the answer and why

    Use OR. Ask again if the name is too short OR too long. A length cannot be below 5 AND above 10 at the same time.

    Flip the question

    Which condition is TRUE for an allowed length?
